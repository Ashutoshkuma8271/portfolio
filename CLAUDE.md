Never use generic AI-generated UI.

Avoid:
- excessive gradients
- random glassmorphism
- excessive rounded cards
- unnecessary animations
- generic purple/blue AI aesthetics
- excessive shadows
- decorative elements without purpose

Prioritize:
- strong typography
- visual hierarchy
- consistent spacing
- premium imagery
- intentional whitespace
- responsive art direction
- subtle micro-interactions
- cinematic but performant motion
- accessibility
- reduced-motion support
- mobile-first behavior
- production-quality code

Before finishing:
1. Run the application.
2. Inspect the UI with Playwright.
3. Check desktop.
4. Check tablet.
5. Check mobile.
6. Check console errors.
7. Verify animations.
8. Fix visual inconsistencies.
9. Run production build.
